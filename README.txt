CCI AVTF Industry Certification Website
Certification cycle 2027–2032
Evidence year 2026–2027

Open index.html in a modern web browser to review the complete website.

The site is self-contained. It does not require a web server, external style
sheet, JavaScript library, font, or image. It includes all 78 rubric evidence
checkpoints, filters, an auditor checklist, a downloadable evidence index, and
downloadable draft packets for every checkpoint.

IMPORTANT
All language marked Draft — replace is prototype content. Restricted items are
designed to remind the editor that student, personnel, budget, safety, and
facility records should not be published openly. Replace draft filenames and
responses with verified CCI evidence before certification review.
